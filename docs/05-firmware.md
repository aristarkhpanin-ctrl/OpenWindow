# 4. Прошивка: от нуля до работающего устройства

Раздел рассчитан на то, что вы **никогда не держали в руках Arduino**.
Каждый шаг — буквальный.

## 4.1. Устанавливаем среду (20 минут)

### Шаг 1. Arduino IDE

Скачайте **Arduino IDE 2.x** с <https://www.arduino.cc/en/software> и установите.

### Шаг 2. Добавляем поддержку ESP32

1. `File` → `Preferences`.
2. В поле **Additional boards manager URLs** вставьте:
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. `OK`.
4. Слева откройте **Boards Manager** (иконка платы), найдите **esp32 by Espressif Systems**.
5. Установите версию **3.1.0 или новее**. Это важно: Zigbee-библиотека
   появилась именно в 3.1.0. Установка займёт несколько минут — пакет большой.

### Шаг 3. Выбираем плату и режим

`Tools` → и выставьте:

| Параметр | Значение |
|---|---|
| Board | **ESP32C6 Dev Module** |
| **Zigbee mode** | **Zigbee ZCZR (coordinator/router)** |
| **Partition Scheme** | **Zigbee ZCZR 4MB with spiffs** |
| USB CDC On Boot | **Enabled** |
| Erase All Flash Before Sketch Upload | **Enabled** (только в первый раз!) |
| Port | появится после подключения платы по USB |

> Если пункта **Zigbee mode** нет — у вас старая версия ядра, вернитесь к шагу 2.
> Если не выставить Partition Scheme, прошивка соберётся, но Zigbee-стек
> не стартует: ему нужен отдельный раздел под сетевые ключи.

### Шаг 4. Открываем скетч

`File` → `Open` → выберите
`firmware/zigbee_window_opener/zigbee_window_opener.ino`.
Файл `config.h` подтянется автоматически и появится второй вкладкой.

## 4.2. Первая прошивка — на столе, без мотора

**Не подключайте мотор к первой прошивке.** Сначала убедимся, что
устройство входит в сеть.

1. Подключите ESP32-C6 к компьютеру по USB-C.
2. Нажмите **Upload** (стрелка вправо).
3. Если не прошивается — зажмите **BOOT**, коротко нажмите **RESET**,
   отпустите BOOT, повторите Upload.
4. Откройте `Tools` → **Serial Monitor**, скорость **115200**.

Вы должны увидеть:

```
=== OpenWindow — Zigbee window opener ===
[INA219] НЕ найден — защита по току отключена
[NVS] полный ход 9000 мс, позиция 100%
[ZB] запуск стека…
[ZB] подключение к сети....
```

Точки будут идти, пока устройство не вступит в сеть — это нормально.
Переходите к `docs/06-integration.md`, добавьте устройство в сеть,
и точки сменятся на `готово`.

## 4.3. Что делает прошивка

### Модель устройства

Устройство объявляет себя как **Window Covering** (кластер ZCL `0x0102`,
тип `AWNING`). Это даёт «бесплатно»:

- команды `Open`, `Close`, `Stop`, `Go to Lift Percentage`;
- атрибут текущей позиции, который координатор опрашивает и показывает;
- готовую сущность `cover.*` в Home Assistant с ползунком.

> **Про проценты.** В стандарте Zigbee `0 % = открыто`, `100 % = закрыто`.
> В Home Assistant у штор наоборот. Пересчёт делает координатор, вам
> ничего править не нужно — просто не пугайтесь, увидев в логах «100 %»
> у закрытого окна.

### Как считается позиция

Энкодера нет, поэтому позиция считается **по времени**:

1. При калибровке привод едет до упора «закрыто», потом до упора «открыто»
   и засекает длительность полного хода → `travelMs`.
2. `travelMs` сохраняется в NVS (переживает перезагрузку и отключение питания).
3. Во время движения позиция интегрируется по времени.
4. **Приезд в крайние положения обнуляет накопленную ошибку** — концевик
   важнее расчёта. Поэтому дрейф не накапливается: каждое полное
   открытие/закрытие «сбрасывает» счётчик.

Это классический подход для приводов штор, точность — единицы процентов.
Если нужна точность лучше — ставьте мотор с энкодером (см. `docs/02-bom.md`).

### Защита от защемления

Каждые 5 мс читается ток мотора через INA219. Если ток держится выше
`CURRENT_STALL_A` дольше `STALL_CONFIRM_MS` (250 мс):

1. мотор останавливается;
2. **отъезжает назад** на `BACKOFF_MS` (700 мс), освобождая зажатое;
3. устройство переходит в состояние `ST_FAULT`, светодиод краснеет;
4. позиция пересчитывается и отправляется координатору.

Первые `INRUSH_IGNORE_MS` (600 мс) после старта ток игнорируется —
пусковой бросок в 2–3 раза выше рабочего и иначе давал бы ложные срабатывания.

### Плавный пуск и торможение

Функция `rampedDuty()` разгоняет ШИМ за 350 мс и снижает его на подходе
к цели. Это заметно продлевает жизнь пластиковой рейке: удар зубьев
на полном моменте — главная причина их срезания.

## 4.4. Калибровка

Обязательна после сборки механики.

1. Убедитесь, что створка свободна и на пути ничего нет.
2. **Зажмите кнопку BOOT на 3–10 секунд**, отпустите.
3. Привод поедет закрываться до упора, потом откроется до упора.
4. В Serial Monitor появится:
   ```
   [CAL] полный ход = 6420 мс, сохранено
   ```
5. Всё, значение записано навсегда (до следующей калибровки).

### Все функции кнопки BOOT

| Нажатие | Действие |
|---|---|
| Короткое (< 3 с) | открыть, если закрыто; закрыть, если открыто; стоп во время движения |
| 3–10 с | калибровка |
| Дольше 10 с | сброс к заводским, выход из Zigbee-сети |

### Светодиод

| Цвет | Значение |
|---|---|
| Мигает жёлтым | ищет сеть |
| Тускло-зелёный | в сети, стоит |
| Синий | едет |
| Красный | сработала защита (`ST_FAULT`) |
| Фиолетовый | идёт сброс к заводским |

## 4.5. Настройка под свою механику

Всё в `config.h`:

| Параметр | Когда менять |
|---|---|
| `MOTOR_INVERT` | окно едет в обратную сторону |
| `CURRENT_STALL_A` | подбор порога защиты — см. `docs/04-electronics.md` |
| `DUTY_RUN` | мотор слишком быстрый/медленный (900 из 1023) |
| `RAMP_MS` | резкий старт, стучат зубья |
| `USE_LIMIT_SWITCHES` | поставьте `0`, если собрали без концевиков |
| `USE_INA219` | поставьте `0`, если собрали без датчика тока (**не советую**) |
| `ZB_ROLE` | `ZIGBEE_END_DEVICE` при питании от батареи |

## 4.6. Типичные проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| `[ZB] стек не стартовал` | не выбран Partition Scheme | `Tools` → `Zigbee ZCZR 4MB with spiffs` |
| Точки идут вечно | сеть не открыта для сопряжения | откройте сеть в HA/Z2M на 4 минуты |
| ESP32 перезагружается при старте мотора | нет конденсатора 470 мкФ | впаяйте его на `VM`/`GND` драйвера |
| `[INA219] НЕ найден` | перепутаны SDA/SCL или нет питания | проверьте GPIO6/GPIO7 и 3,3 В |
| Позиция «уплывает» | не сделана калибровка | зажмите BOOT на 3 с |
| Защита срабатывает постоянно | порог занижен | поднимите `CURRENT_STALL_A` |
| Устройство пропадает из сети | помехи от проводов мотора | скрутите их в косичку, отодвиньте от антенны |
